# Toggle list

A toggle list is a collection of switches, each with a label and an optional
icon button for an action such as removing the item.

<Canvas of={ToggleListStories.Default} />

## List

Put several `ToggleListItem` items in a `ToggleList`. In this example each
switch is controlled, and the remove button takes the item out of the list.

## Without remove

Leave out `onRemove` to show the switch and label only.

## Disabled

`disabled` turns off the switch and the remove button.

## Dark mode

Toggle list has dark mode styles. Switch the Storybook theme to see them.

## Accessibility

`ToggleList` is a list, so screen readers announce how many items it has.
Each switch is named by its `label`, and clicking the label toggles it. The
remove button shows an icon only, so its name must say which item it removes.
When `label` is a string it defaults to "Remove" followed by the label, for
example "Remove Email". When `label` is any other node, `removeLabel` is
required alongside `onRemove`.

## Attributes

`ToggleList` passes any other attribute and the `ref` to its `ul`.
`ToggleListItem` takes the `Switch` props (`checked`, `defaultChecked`,
`onCheckedChange`, `disabled`, `name` and so on) and passes the `ref` to the
switch.

## Example

```tsx
import { ToggleList, ToggleListItem } from '@nearform/quantum'

;<ToggleList>
  {items.map(item => (
    <ToggleListItem
      key={item.id}
      label={item.label}
      checked={item.checked}
      onCheckedChange={checked => toggle(item.id, checked)}
      onRemove={() => remove(item.id)}
      removeLabel={`Remove ${item.label}`}
    />
  ))}
</ToggleList>
```
