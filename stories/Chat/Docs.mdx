# Chat

A set of composable components for building chat interfaces: a message bubble,
a scrollable message list, a text input with send, and a container that ties
them together.

### Message bubble

`ChatBubble` renders a single message. The `received` variant aligns left with
an avatar and sender name; the `sent` variant aligns right.

### Full conversation

`ChatContainer` wraps `ChatList` and `ChatInput` into a bordered panel.
`ChatInput` fires `onSend` on Enter (Shift+Enter for a new line).

<Canvas of={ChatStories.Conversation} />

## Dark mode

Every sub-component reads its colours from semantic tokens that carry dark
counterparts (`background-alt` / `background-alt-dark`, `accent` /
`accent-dark`, etc.), so the chat switches automatically when the page theme
changes.

## Accessibility

- `ChatList` uses `role="log"` with `aria-label="Chat messages"`, which tells
  assistive technology to announce new messages as they appear.
- `ChatInput`'s send button carries `aria-label="Send message"` and is
  keyboard-reachable; Enter submits, Shift+Enter inserts a line break.
- Received bubbles show an `Avatar` with the sender's `name`, providing an
  accessible label for the image fallback.

## Usage

```tsx
import {
  ChatBubble,
  ChatList,
  ChatInput,
  ChatContainer
} from '@nearform/quantum'

<ChatContainer className="h-[500px]">
  <ChatList className="flex-1">
    <ChatBubble variant="received" name="Ada" timestamp="10:30">
      Hello!
    </ChatBubble>
    <ChatBubble variant="sent" timestamp="10:31">
      Hi there!
    </ChatBubble>
  </ChatList>
  <ChatInput onSend={text => console.log(text)} />
</ChatContainer>
```
