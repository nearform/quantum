# Stats

Stats are simple statistics or data shown with an icon, a label and a number.
They can show information about an application or system, such as user
activity, data trends or system health.

<Canvas of={StatsStories.Default} />

## Group

Put several `Stat` items in a `Stats` row. The row wraps when there isn't
enough space.

<Canvas of={StatsStories.Group} />

## Without an icon

The icon is optional.

<Canvas of={StatsStories.WithoutIcon} />

## Dark mode

Stats have dark mode styles. Switch the Storybook theme to see them. The row
has no background, so it takes the colour of the surface it sits on.

## Accessibility

`Stats` renders a description list (`dl`). Each `Stat` is a `div` holding the
label in a `dt` and the value in a `dd`, so screen readers announce each label
with its value. The icon is hidden from assistive technology, so the label must
say what the number means.

Each stat is at least 24px tall, to meet the minimum target size.

## Attributes

`Stats` passes any other attribute and the `ref` to the `dl`. `Stat` passes
them to its `div`.

## Example

```tsx
import { BsPeople, BsStar } from '@nearform/quantum'

;<Stats>
  <Stat icon={BsPeople} label="Contributors" value={20} />
  <Stat icon={BsStar} label="Stars" value={7} />
</Stats>
```
