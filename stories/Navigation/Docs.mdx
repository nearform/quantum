# Navigation

A horizontal navigation bar with links separated by a bottom border. Use it
for top-level page navigation such as settings sections.

<Canvas of={NavigationStories.Default} />

## Parts

- `Navigation` renders a `nav` with a bottom border.
- `NavigationLink` renders an `a`. The active link has a coloured bottom
  border. Pass `asChild` to render your router's link instead.

## Active link

Set `active` on the link for the current page. It gets `aria-current="page"`
and a coloured underline.

<Canvas of={NavigationStories.WithActiveLink} />

## Dark mode

The navigation switches to dark tokens when inside a `.dark` ancestor.

<Canvas of={NavigationStories.DarkMode} />

## Accessibility

Pass `aria-label` to `Navigation` so screen reader users hear the purpose.

## Example

```tsx
<Navigation aria-label="Settings">
  <NavigationLink href="/settings/general" active>
    General
  </NavigationLink>
  <NavigationLink href="/settings/members">Members</NavigationLink>
  <NavigationLink href="/settings/plans">Plans</NavigationLink>
  <NavigationLink href="/settings/billing">Billing</NavigationLink>
</Navigation>
```
