# Sort and show

Sort and show controls let users organise and display the content of a list
or results area. Each control shows a label and its current value. Selecting
the value opens a simple dropdown of options.

<Canvas of={SortAndShowStories.Default} />

## Sort and show results

## Dark mode

Sort and show has dark mode styles.

## Accessibility

Each control is built on the Radix Select primitive, so it has full keyboard
support: `Enter`, `Space` or the arrow keys open the options, the arrow keys
move between them, and `Escape` closes them. The label names the control, and
screen readers announce the selected value with it.

Each control is at least 24px tall, to meet the minimum target size.

## Attributes

`SortAndShow` passes any other attribute and the `ref` to its `div`.
`SortAndShowControl` takes the Radix Select root props (`value`,
`defaultValue`, `onValueChange`, `disabled`, `name` and so on) and passes the
`ref` to the trigger button.

## Example

```tsx
import { SortAndShow, SortAndShowControl } from '@nearform/quantum'

;<SortAndShow>
  <SortAndShowControl
    label="Sort by"
    options={[
      { value: 'alphabetical', label: 'Alphabetical (A-Z)' },
      { value: 'newest', label: 'Newest first' }
    ]}
    value={sort}
    onValueChange={setSort}
  />
  <SortAndShowControl
    label="Show"
    options={[
      { value: '20', label: '20' },
      { value: '50', label: '50' }
    ]}
    value={pageSize}
    onValueChange={setPageSize}
  />
</SortAndShow>
```
