# Link

## Default
The default `nav` variant is for menus and navigation lists.

<Canvas of={LinkStories.Default} />

## Inline
Use `variant="inline"` for a link inside running text. It flows with the
sentence, takes the surrounding text colour and is underlined.

<Canvas of={LinkStories.Inline} />

The component accepts all the properties defined for an HTML Anchor element (<code>AnchorHTMLAttributes</code>) and the following:
