# Textarea

A textarea is a multi-line input field for users to enter longer text, such as comments, descriptions, or messages. It supports label, help text, and various states including error, success, and disabled.

## Dark mode

The `error` and `success` variants drop their `-50` fill to
`background-alt-dark` — the surface the resting field already uses — and the
border and text take the dark half of their descriptor. The light weights are
picked against a white page and do not survive a black one: `feedback-error` is
1.80:1 on `background-alt-dark`, so the field that says something is wrong would
be the one you could not read.

## Attributes

This component accepts all native HTML `<textarea>` attributes, plus:

- `variant`: 'primary' | 'error' | 'success' | 'disabled'
- `labelText`: string (optional)
- `helpText`: string (optional)
- `id`: string (optional, recommended for accessibility)

## Usage

```tsx
import { useState } from 'react'
import { Textarea, TextareaProps } from '@/components/Textarea'

const TextareaDemo = ({
  variant,
  disabled,
  labelText,
  helpText,
  id
}: TextareaProps) => {
  const [value, setValue] = useState('')
  const handleOnChange = (e: React.FormEvent<HTMLTextAreaElement>) => {
    setValue(e.currentTarget.value)
  }
  return (
    <Textarea
      value={value}
      variant={variant}
      onChange={handleOnChange}
      disabled={disabled}
      labelText={labelText}
      helpText={helpText}
      id={id}
      rows={4}
    />
  )
}
export { TextareaDemo }
```
