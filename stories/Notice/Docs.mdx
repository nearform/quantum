# Notice

A notice is a brief message or alert that provides important information or
notifications to users. It is displayed prominently within an interface to
draw the user's attention to a specific piece of content or action. Notices
are typically used to convey urgent updates, alerts, or essential messages
in a clear and noticeable way.

### Default

The default `info` variant is a bordered banner with muted icon styling,
suited for informational messages that do not require immediate action.

<Canvas of={NoticeStories.Default} />

### Variants

Four variants across two axes: `info` and `warning` set the intent, and the
`-filled` suffix swaps the light background for a dark one. The filled
variants use the foreground colour as their background, making them suitable
for messages that need to stand out more.

<Canvas of={NoticeStories.Variants} />

### Dismissible

Pass `onDismiss` to show a close button. Omit it for notices that should
persist.

<Canvas of={NoticeStories.Dismissible} />

### Links and inline content

Children render in a single text container, so a sentence with a link in it
flows as normal text. Use `Link` with `variant="inline"` for links in running
text.

<Canvas of={NoticeStories.WithLink} />

### Title and description

Pass `title` for a short heading and, optionally, `description` for a line
under it. With a title the notice is left-aligned, the icon sits level with
the title, and children can be block content such as paragraphs and lists.
Without a title the notice keeps its centred single-line layout.

<Canvas of={NoticeStories.WithTitle} />

<Canvas of={NoticeStories.TitleVariants} />

### No icon

Pass `icon={null}` to remove the icon entirely.

<Canvas of={NoticeStories.NoIcon} />

## Dark mode

Dark mode swaps the tokens symmetrically: filled variants use
`foreground-dark` / `foreground-inverse-dark` and outlined variants use
`background-dark` with the dark border and text tokens.

## Accessibility

- The notice uses `role="status"` by default so screen readers announce it
  as a live region. Override with `role="alert"` for urgent messages.
- The dismiss button has an accessible label (`dismissLabel`, defaulting to
  "Dismiss").
- The icon is decorative (`aria-hidden`), so the text must carry the full
  meaning.

## Usage

```tsx
import { Link, Notice } from '@nearform/quantum'

<Notice variant="warning-filled" onDismiss={() => setVisible(false)}>
  This project is in active development.
</Notice>

<Notice variant="info">
  Your changes have been saved.
</Notice>

<Notice variant="warning" title="Runs can't start yet">
  <ul className="list-disc pl-5">
    <li>Add an API key in <Link href="/settings" variant="inline">Settings</Link>.</li>
  </ul>
</Notice>
```
