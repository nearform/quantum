# App Header

An App Header sits at the top of an application and provides branding, primary navigation links, and user actions such as notifications and a user avatar. On smaller screens it collapses into a mobile menu toggled by a hamburger button.

## Default

<Canvas of={AppHeaderStories.Default} />

## Without a mobile menu

`AppHeaderActions` is hidden below the `sm` breakpoint by default, on the assumption that its contents are repeated in `AppHeaderMobileMenu` and reached through `AppHeaderMenuButton`. Keep that pairing: if a header has a `AppHeaderMenuButton`, put the actions in the mobile menu too.

A header with no nav and only a few compact actions, such as a language select and a theme toggle, usually has no mobile menu. Set `collapse={false}` on `AppHeaderActions` so the actions stay visible at every width. You don't need to override the `hidden` class yourself.

<Canvas of={AppHeaderStories.WithoutMobileMenu} />

```tsx
<AppHeader>
  <AppHeaderLogo href="/">
    <img src="/logo.svg" alt="My App" />
  </AppHeaderLogo>
  <AppHeaderActions collapse={false}>
    <LanguageSelect />
    <ThemeToggle />
  </AppHeaderActions>
</AppHeader>
```

## Structure

```bash
└── AppHeader
    ├── AppHeaderLogo
    ├── AppHeaderNav
    │   └── AppHeaderLink
    ├── AppHeaderActions
    └── AppHeaderMenuButton
AppHeaderMobileMenu (sibling, below header)
    └── AppHeaderLink
```

## Example

```tsx
import { useState } from 'react'
import {
  AppHeader,
  AppHeaderLogo,
  AppHeaderNav,
  AppHeaderLink,
  AppHeaderActions,
  AppHeaderMenuButton,
  AppHeaderMobileMenu,
  Avatar,
  IconButton
} from '@nearform/quantum'
import { BsBell, BsSearch } from 'react-icons/bs'

export const MyAppHeader = () => {
  const [menuOpen, setMenuOpen] = useState(false)
  return (
    <>
      <AppHeader>
        <AppHeaderLogo href="/">
          <img src="/logo.svg" alt="My App" />
        </AppHeaderLogo>

        <AppHeaderNav aria-label="Main">
          <AppHeaderLink href="/dashboard" active>
            Dashboard
          </AppHeaderLink>
          <AppHeaderLink href="/projects">Projects</AppHeaderLink>
        </AppHeaderNav>

        <AppHeaderActions>
          <IconButton
            variant="tertiary"
            size="sm"
            icon={<BsSearch />}
            label="Search"
          />
          <IconButton
            variant="tertiary"
            size="sm"
            icon={<BsBell />}
            label="Notifications"
          />
          <Avatar size="sm" name="Jane Doe" />
        </AppHeaderActions>

        <AppHeaderMenuButton
          open={menuOpen}
          onClick={() => setMenuOpen(v => !v)}
        />
      </AppHeader>

      <AppHeaderMobileMenu open={menuOpen}>
        <AppHeaderLink href="/dashboard" active>
          Dashboard
        </AppHeaderLink>
        <AppHeaderLink href="/projects">Projects</AppHeaderLink>
      </AppHeaderMobileMenu>
    </>
  )
}
```
