# BackLink

A back link is a text link with an arrow pointing left. It takes users back to
the previous screen, page or location in their journey.

<Canvas of={BackLinkStories.Default} />

## Small

`size="sm"` shows the arrow on its own, for mobile layouts. The label stays in
the link for screen reader users, so the link is still announced as "Back".

<Canvas of={BackLinkStories.Small} />

## Custom label

The label defaults to "Back". Pass children to say where the link goes.

<Canvas of={BackLinkStories.CustomLabel} />

## Dark mode

<Canvas of={BackLinkStories.DarkMode} />

The back link has dark mode styles.

## Accessibility

The back link renders an `a`, so it needs an `href` to be focusable. To go
back in the browser history, pass an `href` for the previous page and handle
`onClick`:

```tsx
<BackLink
  href="/results"
  onClick={e => {
    e.preventDefault()
    history.back()
  }}
/>
```

The arrow is hidden from assistive technology.
