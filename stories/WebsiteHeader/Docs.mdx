# Website Header

A Website Header sits at the top of a web page and provides branding, primary navigation links, and action items such as external links or call-to-action buttons. On smaller screens it collapses into a mobile menu toggled by a menu button.

## Default

<Canvas of={WebsiteHeaderStories.Default} />

## Without a mobile menu

`WebsiteHeaderActions` is hidden below the `sm` breakpoint by default, on the assumption that its contents are repeated in `WebsiteHeaderMobileMenu` and reached through `WebsiteHeaderMenuButton`. Keep that pairing: if a header has a `WebsiteHeaderMenuButton`, put the actions in the mobile menu too.

A header with no nav and only a few compact actions, such as a language select and a GitHub link, usually has no mobile menu. Set `collapse={false}` on `WebsiteHeaderActions` so the actions stay visible at every width. You don't need to override the `hidden` class yourself.

<Canvas of={WebsiteHeaderStories.WithoutMobileMenu} />

```tsx
<WebsiteHeader>
  <WebsiteHeaderLogo href="/">
    <img src="/logo.svg" alt="My App" />
  </WebsiteHeaderLogo>
  <WebsiteHeaderActions collapse={false}>
    <LanguageSelect />
    <ThemeToggle />
  </WebsiteHeaderActions>
</WebsiteHeader>
```

## Structure

```bash
└── WebsiteHeader
    ├── WebsiteHeaderLogo
    ├── WebsiteHeaderNav
    │   └── WebsiteHeaderLink
    ├── WebsiteHeaderActions
    └── WebsiteHeaderMenuButton
WebsiteHeaderMobileMenu (sibling, below header)
    └── WebsiteHeaderLink
```

## Example

```tsx
import { useState } from 'react'
import {
  WebsiteHeader,
  WebsiteHeaderLogo,
  WebsiteHeaderNav,
  WebsiteHeaderLink,
  WebsiteHeaderActions,
  WebsiteHeaderMenuButton,
  WebsiteHeaderMobileMenu,
  Button
} from '@nearform/quantum'

export const MyHeader = () => {
  const [menuOpen, setMenuOpen] = useState(false)
  return (
    <>
      <WebsiteHeader>
        <WebsiteHeaderLogo href="/">
          <img src="/logo.svg" alt="My App" />
        </WebsiteHeaderLogo>

        <WebsiteHeaderNav aria-label="Main">
          <WebsiteHeaderLink href="/docs" active>
            Docs
          </WebsiteHeaderLink>
          <WebsiteHeaderLink href="/blog">Blog</WebsiteHeaderLink>
        </WebsiteHeaderNav>

        <WebsiteHeaderActions>
          <Button size="sm">Get started</Button>
        </WebsiteHeaderActions>

        <WebsiteHeaderMenuButton
          open={menuOpen}
          onClick={() => setMenuOpen(v => !v)}
        />
      </WebsiteHeader>

      <WebsiteHeaderMobileMenu open={menuOpen}>
        <WebsiteHeaderLink href="/docs" active>
          Docs
        </WebsiteHeaderLink>
        <WebsiteHeaderLink href="/blog">Blog</WebsiteHeaderLink>
        <Button size="sm">Get started</Button>
      </WebsiteHeaderMobileMenu>
    </>
  )
}
```
