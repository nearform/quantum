# Input

A single-line text field. It renders the label, the field and its help text as
one group, wires them to each other, and puts a clear button at the end of the
field. Giving it `type="search"` also puts a magnifier at the start.

## Sizes

Three heights: `sm` is 37px, `default` is 42px and `lg` is 48px.

The first two come from the design file, and are the same two heights as
[Select](?path=/docs/form-select--docs)'s `sm` and `lg`, so an input and a
select sit in a row without either of them having to be nudged. The names are
not the same — 42px is the size the design calls regular, so it is the default
here, and `Select` had already spent `lg` on it.

`lg` is not in the design file. It is 48px because that is the height of a
large [Button](?path=/docs/form-button--docs), in both of that component's
variants, so a large field and the button that submits it match.

The height is set on the field rather than added up out of padding and text, so
it holds whatever font size the field inherits, and a disabled field — which
drops its border — is the same height as an enabled one.

## Icons

The leading icon is drawn at 16×16 and the clear icon at 12×12, and the field
sizes both of them, so an icon passed as `leftSideChild` or `rightSideChild`
comes out at the size the design specifies rather than at the `1em` that
`react-icons` defaults to.

The clear button itself is 24×24 — the smallest target
[WCAG 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)
accepts. It grows into the field's own padding rather than pushing the icon
inwards, so the cross stays where it is drawn.

## Accessibility

- The clear button has no text, so it carries an accessible name of its own.
  `clearLabel` renames it for its context — "Clear search" reads better than
  "Clear input" on a search field.
- `labelText` is associated with the field, and `helpText` describes it rather
  than naming it. An `aria-describedby` you pass in is kept alongside the help
  text rather than replaced by it.
- Both icons are hidden from assistive technology. An icon passed in as
  `leftSideChild` or `rightSideChild` should be too — it repeats what the label
  already says.

## Usage

```tsx
import { useState } from 'react'
import { Input, InputProps } from '@nearform/quantum'

const InputDemo = (props: Omit<InputProps, 'onChange' | 'onClear'>) => {
  const [value, setValue] = useState('')
  const handleOnClear = () => {
    setValue('')
  }
  const handleOnChange = (e: React.FormEvent<HTMLInputElement>) => {
    setValue(e.currentTarget.value)
  }
  return (
    <Input
      value={value}
      onClear={handleOnClear}
      onChange={handleOnChange}
      {...props}
    />
  )
}
export { InputDemo }
```
