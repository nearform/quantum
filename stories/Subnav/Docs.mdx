# Subnav

A subnav lists the pages in one section of a site, under a heading for that
section. Use it at the side of a page, next to the main content.

<Canvas of={SubnavStories.Default} />

## Parts

- `Subnav` renders a `nav`. It is labelled by its heading.
- `SubnavHeading` renders an `h2` for the section name. Pass `asChild` to
  render another heading level.
- `SubnavList` renders the `ul` that holds the links.
- `SubnavItem` renders an `li` for each link.
- `SubnavLink` renders an `a`. It is underlined on hover. Pass `asChild` to
  render your router's link instead.

## Active link

Set `active` on the link for the current page. It is bold and has
`aria-current="page"`.

<Canvas of={SubnavStories.WithActiveLink} />

## Without a heading

Pass `aria-label` to `Subnav` when it has no heading.

<Canvas of={SubnavStories.WithoutHeading} />

## Dark mode

The subnav has dark mode styles. Switch the Storybook theme to see them.

## Accessibility

The `nav` takes its name from `SubnavHeading`, so screen reader users hear
the section name. `aria-label` or `aria-labelledby` on `Subnav` replaces it.

## Example

```tsx
<Subnav>
  <SubnavHeading>Guides</SubnavHeading>
  <SubnavList>
    <SubnavItem>
      <SubnavLink href="/guides/start" active>
        Getting started
      </SubnavLink>
    </SubnavItem>
    <SubnavItem>
      <SubnavLink href="/guides/theming">Theming</SubnavLink>
    </SubnavItem>
  </SubnavList>
</Subnav>
```
