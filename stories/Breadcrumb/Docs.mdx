# Breadcrumb

A breadcrumb shows the path from the top of a site to the current page. Each
step is a link back to that level, and the last step is the current page.

<Canvas of={BreadcrumbStories.Default} />

## Parts

- `Breadcrumb` renders a `nav` labelled "Breadcrumb".
- `BreadcrumbList` renders the `ol` that holds the steps.
- `BreadcrumbItem` renders an `li` for each step.
- `BreadcrumbLink` renders an underlined `a`. Pass `icon` to show an icon
  before the link, such as a house for the home page. Pass `asChild` to render
  your router's link instead.
- `BreadcrumbPage` renders the current page. It is not a link, and it has
  `aria-current="page"`.
- `BreadcrumbSeparator` renders the chevron between steps.

## Accessibility

The `nav` has the label "Breadcrumb" so screen reader users can find it. Pass
`aria-label` to change it, for example when the page has more than one
breadcrumb. Separators and icons are hidden from assistive technology.

## Example

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/" icon={BsHouse}>
        Home
      </BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Components</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```
