# Slider

A slider allows users to select a value or range from a continuous or stepped interval by dragging a thumb along a track. Sliders are commonly used for adjusting settings such as volume, brightness, or price ranges.

<Canvas of={SliderStories.Default} />

## With end labels

Use `minLabel` and `maxLabel` to display labels at each end of the slider track.

<Canvas of={SliderStories.WithEndLabels} />

Use two thumbs to select a range of values.

## With label

Use the `label` prop to render a label above the slider. The label is automatically connected to the slider thumbs for accessibility.

<Canvas of={SliderStories.WithLabel} />

## End labels below

Set `endLabelPosition="below"` to place labels underneath the track, aligned to each end.

<Canvas of={SliderStories.EndLabelsBelow} />

## Custom end labels

End labels accept any React node, so you can use text like "Low" and "High" instead of numbers.

<Canvas of={SliderStories.CustomEndLabels} />
