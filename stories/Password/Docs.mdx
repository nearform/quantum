# Password

Password is an input field for entering passwords. The input is masked by
default, and the masking can be toggled with an optional reveal button. It is
[Input](?path=/docs/form-input--docs)'s field, so the two share their
appearance, their sizes and their label and help text wiring.

## Sizes

The same three heights as `Input`, from the same variants: `sm` is 37px,
`default` is 42px and `lg` is 48px. A password field and a text field with the
same `size` are the same height, which is the point of sharing them.

A `Select` in the same row is not, however — its names are offset by one. See
[the table in Input's docs](?path=/docs/form-input--docs#matching-the-other-form-controls)
for every control's height.

## Dark mode

Toggle the theme in the toolbar to see it.

The field is `Input`'s container, so the `error` variant behaves the same way
there: the `-50` fill drops to `background-alt-dark` and the border and text
take `feedback-error`'s dark half. The light weight is 1.80:1 on
`background-alt-dark`, so the field that says something is wrong would be the
one you could not read.

## Accessibility

- The mask toggle has no text, so it carries an accessible name of its own and
  reports its state: `aria-pressed` follows the mask, and `showLabel` /
  `hideLabel` translate the name. It sits in a 24×24 target, which is the
  smallest [WCAG 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)
  accepts.
- `labelText` is associated with the field, and `helpText` describes it rather
  than naming it. An `aria-describedby` you pass in is kept alongside the help
  text rather than replaced by it.
- A password field with no visible label still needs a name — pass `labelText`,
  or an `aria-label` where the design has no room for one. A placeholder is not
  a label.

## Usage

```tsx
import { useState } from 'react'
import { Password, PasswordProps } from '@nearform/quantum'

const PasswordDemo = (props: Omit<PasswordProps, 'onChange'>) => {
  const [value, setValue] = useState('')

  const handleOnChange = (e: React.FormEvent<HTMLInputElement>) => {
    setValue(e.currentTarget.value)
  }

  return <Password value={value} onChange={handleOnChange} {...props} />
}
export { PasswordDemo }
```
