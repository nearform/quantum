# Split Button

A split button pairs a main action with a menu of related actions. The label
runs the main action straight away, and the chevron beside it opens a menu of
alternatives, such as "Save" with "Save as draft" and "Save and close" behind
it. Use it when one action is by far the most common and the others are
variations of it. When the actions are equally likely, use a
[Button Group](?path=/docs/components-buttongroup--docs) instead.

## Disabled

`disabled` disables both the main action and the menu. To disable a single
entry in the menu, pass `disabled` to that `SplitButtonItem`.

## States

Hover each half to see its hover state, and tab through to see the focus
ring. The ring is drawn around the whole control, and the focused half takes
its focus colour. The menu trigger keeps its pressed colour while the menu is
open.

## Dark mode

Both variants have dark mode styles.

## Accessibility

The main action and the menu trigger are two separate buttons, so each gets
its own tab stop. The trigger has only an icon, so it is named with
`menuLabel`, which defaults to "More options". Name it for what the menu
holds, for example "More save options", so it makes sense out of context.

The menu is a [Radix Dropdown Menu](https://www.radix-ui.com/primitives/docs/components/dropdown-menu).
It opens with <kbd>Enter</kbd>, <kbd>Space</kbd> or <kbd>ArrowDown</kbd>,
the arrow keys move between items, and <kbd>Escape</kbd> closes it and
returns focus to the trigger.

### SplitButtonItem

Takes the props of a Radix `DropdownMenu.Item`. The most useful are
`onSelect`, which runs when the item is chosen, and `disabled`.

## Example

```tsx
<SplitButton label="Save" menuLabel="More save options" onClick={save}>
  <SplitButtonItem onSelect={saveDraft}>Save as draft</SplitButtonItem>
  <SplitButtonItem onSelect={saveAndClose}>Save and close</SplitButtonItem>
  <SplitButtonSeparator />
  <SplitButtonItem disabled>Save as template</SplitButtonItem>
</SplitButton>
```
